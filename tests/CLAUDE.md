# Test boundary

Root rules: `../AGENTS.md`. Depth: `../docs/testing.md` and `../docs/architecture.md`.

Search for the production symbol and its closest focused test before opening broad
regression files. Keep tests offline and deterministic: use tracked raw envelopes, never
live sportsbook requests. Do not hand-edit or synthesize captures to make a source
contract pass. Run the smallest relevant node or file first; use the documented full
suite only after focused checks.
